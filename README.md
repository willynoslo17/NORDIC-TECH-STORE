# Nordic Tech Store

Static international storefront for Norway, Europe and Peru, operated by ML Internasjonal Handel.

## Supplier integration layer

`/api/supplier-route` exposes the first portable supplier-routing service. It selects an eligible offer using market, stock, landed cost, delivery window, margin, warehouse region, supplier priority and tracking availability.

Provider credentials are never committed. Configure them as Netlify environment variables when issued:

- `DROPI_API_TOKEN`
- `BIGBUY_API_TOKEN`
- `CJ_API_KEY`
- `SYNCEE_API_KEY`
- `DSERS_API_KEY`

No delivery promise is generated by this service. Customer-facing delivery estimates must come from the selected provider for the exact product and destination.
## Direct commerce activation

The store has its own `/api/cj-products` catalog endpoint and a validated `/api/order` endpoint. Configure `CJ_API_KEY` and the shared `MAKE_ORDERS_WEBHOOK` in Netlify; credentials must never be committed.

The storefront remains in non-charging request mode until supplier stock, landed cost, delivery time, product compliance and a payment provider are verified. Before enabling payment for a SKU, record its manufacturer, responsible economic operator, safety warnings, destination availability, current shipping quote, VAT treatment and return address.
